# ⚠️ DEPRECATED — Mapping Guide

> **This mapping guide has been moved out of INTENT-7 scope.**

INTENT-7 is a syntactic protocol (SIDL). It no longer maintains static mapping tables
between intents and tool capabilities.

**Intent-to-tool mapping is now the responsibility of the orchestration layer**
(e.g., Anaphase). See the orchestration layer's documentation for routing configuration.

The original mapping guide content has been archived. For historical reference,
see the git history of this file.
